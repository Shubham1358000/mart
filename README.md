# 🛒 Mart - Fresh Fruits & Vegetables Store

![Fresh fruits and vegetables banner](https://images.unsplash.com/photo-1542838132-92c53300491e?auto=format&fit=crop&w=1200&q=80)

A colorful and simple grocery-style web app for browsing fresh fruits and vegetables. This project is built to showcase product cards, detailed product pages, and a clean modern visual design inspired by farm-to-table shopping.

## 🌟 Project Overview

Mart is a lightweight web application that allows users to:

- View a homepage with fresh product cards
- See prices, quantities, and origin information
- Open a product details page for each item
- Explore a friendly UI using emoji-based visuals and a green-themed design

The project combines HTML, CSS, JavaScript, and a small Express server to serve dynamic product data from `data.json`.

## ✨ Key Features

- 🍋 Fresh product catalog with fruit and vegetable listings
- 🧺 Product cards with price, quantity, and origin details
- 🔍 Individual product detail page for each item
- 🌿 Organic badge support for selected products
- 📱 Responsive layout for desktop and mobile screens
- ⚡ Light static data-driven design using JSON
- 🖥️ Node.js + Express backend for serving pages

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- JSON data files


## 🚀 Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start the app

```bash
npm start
```

Then open:

```text
http://localhost:8080
```

### 3. Development mode

```bash
npm run dev
```
